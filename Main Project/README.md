# Adidas US Sales Data Analysis – Main Project

## Project Overview
This project analyzes Adidas US sales data with the objective of
understanding sales performance, operating profit behavior,
retailer contribution, and regional trends. The analysis focuses on
cleaning real-world sales data, performing exploratory data analysis
(EDA), and creating meaningful visualizations to support
data-driven business insights.

## Dataset Information
- Dataset Name: Adidas US Sales Dataset
- Source: Kaggle
- Time Period Covered: 2020–2021
- Data Type: Sales transactions across retailers and regions
- Note: A cleaned subset of the dataset was used for analysis

## Tools & Technologies Used
- Python
  - Pandas – data cleaning and manipulation
  - NumPy – numerical operations
  - Matplotlib – data visualization
- Power BI
  - Dashboard creation
  - KPI cards and interactive visuals

## Data Cleaning & Preparation
The following data preparation steps were performed using Python:
- Removal of duplicate records
- Handling missing and inconsistent values
- Conversion of date columns into proper datetime format
- Standardization of categorical fields such as region and retailer
- Validation of sales-related fields to ensure accuracy
- Creation of derived metrics such as Profit Margin (%)

## Exploratory Data Analysis (EDA)
EDA was conducted to understand overall sales behavior and patterns:
- Analysis of total sales and operating profit distribution
- Region-wise and retailer-wise sales comparison
- Identification of trends in units sold across transactions
- Examination of operating profit variation across retailers
- Use of histograms, bar charts, line plots, and scatter plots

## Key Business Insights
- Operating profit is influenced more by profit margins than by total sales volume
- Certain retailers achieved higher operating profit despite lower total sales
- Sales and profitability varied significantly across different US regions
- High sales volume does not always guarantee higher profitability
- Visual analysis helped identify strong-performing retailers and regions

## Data Visualization
- Python was used to create analytical charts for EDA and insights
- Power BI was used to recreate key visualizations in an interactive dashboard
- Dashboard elements include:
  - KPI cards for Total Sales and Operating Profit
  - Retailer-wise and Region-wise performance charts
  - Trend analysis visuals for better business understanding

## Outcome & Deliverables
- Cleaned and processed dataset ready for analysis
- Python-based EDA notebook with visual insights
- Interactive Power BI dashboard
- Clear business-oriented conclusions derived from data

## Conclusion
This project demonstrates the complete data analysis workflow,
starting from raw data cleaning to insight generation and dashboard
creation. The analysis highlights how profitability depends not only
on sales volume but also on pricing and margins, providing valuable
insights for business decision-making.
